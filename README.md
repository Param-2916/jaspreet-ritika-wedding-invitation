# Saanjh — A Punjabi Wedding Story

Standalone React + Vite wedding invitation website for Jaspreet Singh & Ritika.

## Run locally

1. Install Node.js 20 or newer.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. Run `npm run build` to create the production site in `dist/`.

## Assets

- `public/assets/jr-monogram.png` — transparent J & R monogram.
- `public/assets/music.mp3` — optional future background music. Add this file when selected; the player is already wired to this path.
